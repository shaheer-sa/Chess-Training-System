# ADR 003 — Classification Vocabulary
Status: Accepted
Internal code     | UI label        | Color  | Icon
safe              | Safe            | green  | ✓
even_trade        | Even trade      | blue   | ⇄
loses_material    | Loses material  | red    | ⚠
unclear           | Unclear         | yellow | ?
- One concept, one name, in Analysis and Training alike.
- Color is never the only signal: label + icon always accompany it.
- Training answer options = the same four labels, plus a separate,
  UNGRADED "Not sure" option.
- "Safe" never means "good move" or "best move".
