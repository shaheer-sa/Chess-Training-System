# 004 - Piece Assets

## Context
We need an open-licensed SVG piece set compatible with our GPL-3.0 project to render the chess board in the UI.

## Decision
We will use the Colin M. Burnett (CBurnett) SVG chess piece set.
- Source: Wikimedia Commons (https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces)
- License: GNU General Public License (GPL) / GNU Free Documentation License (GFDL) / CC-BY-SA
- The GPL and CC-BY-SA licenses are perfectly compatible with our GPL-3.0 codebase.

The license text for the piece set will be included in the repository.
